# iPhone／iPadからClaudeへ添付する資料

設定は無料プラン、Sonnet 5.5、思考レベル「高」。まず理科1本だけを送る。

1. `01_science_audit.pdf` を開き、共有・保存メニューから「ファイルに保存」。
2. Claudeの新しい会話を開く。添付メニュー（＋など）から保存したPDFを1本付ける。
3. 「添付PDFの指示どおりに全問を監査してください。」と入力して送信する。
4. 返答を元のChatGPT会話へ戻す。その後、数学・英語も別々の新規会話で同じ操作をする。

3本を一緒に添付しない。長文の選択・コピー、GitHub接続は不要。共有ボタンの位置や表示名はアプリ・OSの版による。

PDFの内容は固定SHA `839d39db1326d7c810600b62dc704c868ebd9a58` の追加75問と修正5問。理科25・数学25・英語30。今回別に作成した国語25問は含めない。各PDFは監査指示・全問題・選択肢・正答・解説を含み、理科はグラフの再描画と元SVGソース、英語は修正前設問も含む。

全80 IDと本文は元の生徒HTML埋込データと一致を確認。PDFの全元テキストを抽出できること、日本語の表示をPDFレンダリングで確認した。iPhone実機操作やClaudeへの実添付・実監査は未実施。PDFはHeiseiKakuGo-W5の標準CJKフォント指定を使用するため、表示は端末のPDFビューアのフォント対応にも依存する。
