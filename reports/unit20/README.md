# まなびの庭 全単元20問版

中1〜中3の主要5教科。授業試用版に登録されていた201単元に1,967問を補充し、各単元20〜30問、合計4,323問にした。各単元で5問練習または20問に挑戦でき、解答直後に解説を表示する。英語の聞き取りは合成音声60本を同梱。計算条件や英文・場面を変えた反復問題も含む。単元名と学年は既存の教材一覧に従う。

`python3 scripts/build_unit20.py /path/to/empty-output` を実行すると、生徒配布用HTML、教員用CSV、単元別件数が生成される。Python 3とFlite・MP3対応のFFmpegが必要。配布する manabi_20.html は、保存してPCのブラウザで開くと学年と教科を選べる。教材と音声を内蔵。学習記録はブラウザに保存する。

検査は `node scripts/verify_unit20.cjs /path/to/empty-output /path/to/baseline/dist`。比較元は授業試用版 `70a5ad790b07e4bc893c7c8e540c574d42105420` の生成物。全201単元の5問・20問出題と未出題優先、4,323問の登録正答・代表誤答、音声同梱、既存問題パックの一致を確認。Chromeでは中3理科「遺伝の規則性」の20問ボタン、最初の出題、選択後の正解・解説を確認した。問題内容の全件校閲、iPhone実機、授業での試用は未実施。

参照資料は前版の reports/release_prep/v2/README.md を参照。単元表はアプリの登録範囲であり、学習指導要領の小単元をすべて列挙したものではない。
