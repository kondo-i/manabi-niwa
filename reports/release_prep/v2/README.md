# まなびの庭 授業試用版 2026-11-13

中1〜中3・5教科の授業練習を238問、47単元追加。前回の制作チェック表で新問が0だった32項目に練習を追加し、数学・理科の応用と国語読解の15単元も新設した。本文・英語音声原稿・解答は data/expansion/v2/ に収録。英語発話は声に出す練習と表現の選択式採点、英作文は空欄入力を採用。学年は授業向けの目安で、学校の進度に合わせて選ぶ。

`python3 scripts/build_release_runtime_v2.py /path/to/new-folder` で生成。Python 3とFlite・MP3対応のFFmpegを使用。manabi_classroom.html を保存し、PCのブラウザで開いて上部から学年・教科・単元を選ぶ。1回5問。英語の聞き取り15問は合成音声を内蔵し、解答後に原文を表示する。学習記録はブラウザ内に保存される。teacher_answers.csv は教員用で、新作問題の正答・解説・音声原稿を収録。

通常問題2,356問を格納し、うち2,351問を練習可能。新作の保存ID・設問文の重複は0件。既存の問題パックは前回版とバイト一致。全199出題可能単元から5問を読み込み、通常問題の登録正答・代表誤答を採点検査。新作238問の正答と解説を実際の回答処理で検査し、数値解答39問は条件から別計算で照合。Chromeで中2英語の聞き取りの再生、選択肢、正解・原文表示を確認。合成音声15件のファイル同梱は照合済み。実際の生徒での試用、iPhoneでのローカルHTML実行、独立した内容監査は未実施。前回の制作チェック表は単元の大枠で、今回の補充は全小単元の網羅を表さない。
