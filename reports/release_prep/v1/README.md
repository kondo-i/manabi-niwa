## 再現

Python3 + sympy（実行検証時1.14.0）、Node.jsを用意する。外部サイトの配信操作は不要。

```sh
python3 scripts/rebuild_expansion_v1.py
python3 scripts/build_curriculum_checklist.py
python3 scripts/verify_expansion_v1.py
python3 scripts/build_release_runtime_v1.py /tmp/manabi-release-review
node scripts/verify_release_runtime_v1.cjs /tmp/manabi-release-review
node --test app_drafts/strengths-v5/choose.test.cjs
```

runtime出力先は空フォルダを指定。確認アプリを自分のPCで見る場合は、その出力先で `python3 -m http.server --directory dist 8000` を実行し、ブラウザで http://localhost:8000 を開く。教材・記録は試作用。mainや配信アプリは変更していない。公開判断はrelease_gates.jsonの未了項目を解消してから行う。

## 監査負担の配分

制作、一次資料整理、全件機械検査、独立数値解法、差分・再現資料、画面検査はCodex側で行う。Claudeに全数再読を毎回依頼せず、変更箇所・意味が競合しやすい誤答・計算前提・学年の境界などの抽出確認に絞る。抽出監査を全件合格に読み替えない。Claudeへ依頼しない項目も内容確認済みにしない。
