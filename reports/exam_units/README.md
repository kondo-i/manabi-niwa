## 学校の範囲との照合

[中学校学習指導要領の案内](https://www.mext.go.jp/a_menu/shotou/new-cs/1387016.htm)と出版社の学習計画を参照した。小単元はアプリの出題範囲で、学校が指定する教科書のページとの対応は未確認。国語・英語の個別教材本文や記述対策、社会の世界の州別・日本の地域別の細分化、理科の実験資料を読み取る問題には追加の余地がある。既存の語彙の学年分類を引き継いでいる。

## 再現方法

Python 3とNode.jsを使用する。比較元は `54450a064ed78dcf48759511a711a6bdc0500f55`。国語の入力は別ブランチ `draft/japanese-vocab-v10-20261109` の `733c50ca5d46aea2b5367a90f8f06e62d23b746e` にある `data/v10/questions.json`。入力のSHA-256は `f84a54070d254a16a35416a58ef8a5111df12e739e0d3972fa8988ad8436749a`。

```sh
git fetch origin draft/japanese-vocab-v10-20261109
git show 733c50ca5d46aea2b5367a90f8f06e62d23b746e:data/v10/questions.json > /tmp/manabi-vocab-v10.json
python3 scripts/build_unit20.py /tmp/manabi-unit20
python3 scripts/build_exam_units.py /tmp/manabi-exam --base /tmp/manabi-unit20 --vocabulary /tmp/manabi-vocab-v10.json
node scripts/verify_exam_units.cjs /tmp/manabi-exam /tmp/manabi-unit20 /tmp/manabi-vocab-v10.json
```

`manabi_exam.html` をブラウザで開き「定期テスト対策」を選ぶ。機械検査では、全小単元の5問・20問の抽出、学年・教科の一致、同一セッションのID重複防止、正答・誤答の採点を検証した。中2理科の電流の5小単元を選ぶと、20問に各4問含まれた。既存問題データのバイト一致と国語第10稿の1,040問の本文・選択肢・正答・解説の一致を確認した。問題の全件内容監査と生徒による実機試験は未実施。
